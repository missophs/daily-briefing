## SKILL: daily-briefing

**Trigger:** "morning briefing" / "daily brief" / "what's on my plate today" / "prep my day" / "start my day"

Works standalone or with connectors.

### Standalone (no tools)
Tell me: today's meetings, key deals, priorities. Get: prioritized 2-min briefing.

### Supercharged (connected tools)
| Connector | Adds |
|-----------|------|
| Calendar | Today's meetings, attendees, times |
| CRM | Pipeline alerts, closing deals, stale deals, overdue tasks |
| Email | Unread from key accounts, waiting on replies |
| Enrichment | Overnight signals — funding, hiring, news |

### Output Sections
1. **#1 Priority** — single most important thing
2. **Today's Numbers** — pipeline / meetings / actions (CRM required)
3. **Today's Meetings** — time, attendees, context, prep
4. **Pipeline Alerts** — needs attention + closing this week
5. **Email Priorities** — respond + waiting on reply
6. **Suggested Actions** — top 3, with reasons

### Priority Logic
1. Deal closing today/tomorrow → close it
2. Meeting with high-value opp → prep it
3. Unread email from decision-maker → respond first
4. Deal closing this week → move it
5. Stale deal 7+ days → touch it

### Quick Mode
Say "quick brief" or "tldr my day":
- #1 priority
- Meetings list
- Top 2 alerts
- Single do-now action

### End of Day Mode
Say "wrap up my day":
- Completed meetings + outcomes
- Pipeline changes
- Tomorrow's focus
- Open loops
